STEP 01

欢迎使用 SignDock

SignDock 是一个 Windows 托盘小工具，帮你每日自动领取四款开发者产品的免费额度，不用再手动去几个网站点击登录。

  • WorkBuddy（腾讯） — AI 助手积分
  • Trae（字节跳动） — AI 编程额度
  • Qoder — 每日 100 秒点
  • 秒哒（百度） — 每日 100 秒点

本教程共 8 步，跟着做大概 5 分钟就能跑通。

开始 下一步：下载安装 →
STEP 02

下载安装

下载 SignDock-portable-0.1.0-windows-x64.zip（4.3 MB），解压到任意目录。

推荐路径： D:\SignDock\ 或 C:\Users\<你的用户名\>\SignDock\

解压后进入 SignDock\ 目录，双击 SignDock.exe 启动。

提示：绿色版免安装，Win10 2004+ 或 Win11 都能直接跑。首次运行会检查 WebView2 Runtime（新版 Win10/11 已内置）。
← 上一步 下一步：认识托盘 →
STEP 03

认识托盘图标

启动成功后，屏幕右下角会出现一个绿色托盘图标，表示 SignDock 正在后台运行。

  • 右键托盘 → 打开设置 / 立即签到（全部）/ 退出
  • 首次运行会弹出设置窗口
开机自启：右键 SignDock.exe → 发送到 → 启动菜单。或按 Win+R 输入 shell:startup 手动拖入。
← 上一步 下一步：界面全景 →
STEP 04

设置窗口全景

设置窗口按产品分为 4 个 Tab，每款产品一张卡片。每个卡片包含：

  • 模式（关闭 / 仅提醒 / 自动签到）
  • 时间（每日触发时刻）
  • 重试策略（次数 + 间隔）
  • 账号信息和积分余额
  • 操作按钮：保存 / 立即执行一次 / 刷新积分
  • 最近 5 条签到日志

右上角彩色徽章是今日执行状态。

← 上一步 下一步：配置 Trae →
STEP 05

配置 Trae（最简单）

切到 Trae Tab → 模式选 自动签到 → 时间设 10:00 之后 → 点 保存。

SignDock 会自动读取本机 Trae 的登录态，你不需要登录任何账号。

前提：电脑上已经装过并登录过 Trae IDE。SignDock 只读不写，不会改你的登录状态。

保存后点 立即执行一次，看到"签到成功"就成功了。

← 上一步 下一步：WorkBuddy →
STEP 06

配置 WorkBuddy（OAuth）

切到 WorkBuddy Tab，配置模式和时间后，点卡片下方的 「登录并获取 token」。

  1. 系统浏览器自动打开官方登录页
  2. 用 WorkBuddy 账号登录一次
  3. SignDock 自动收到授权，DPAPI 加密后落盘
  4. 之后自动续期，无需再操作
注意：SignDock 从不要求你粘贴任何 token。所有凭证都是自动获取，不经过键盘。
← 上一步 下一步：秒哒 →
STEP 07

配置秒哒（专属登录窗口）

秒哒最特殊——没有"领取"接口，服务端靠"当天登录事件"触发发放。SignDock 用自己的 WebView2 窗口处理：

  1. 点 「打开登录窗口」 → SignDock 弹出一个专属登录窗口
  2. 在窗口里登录秒哒账号
  3. 回到设置页点 「我登录好了，取会话」
  4. 会话被 DPAPI 封存，之后每天自动代为访问
免费版限制：每月最多领 7 天。领完之后当天没发放属正常。
← 上一步 下一步：完成 →
STEP 08

日常使用完成

配置好之后，SignDock 会每日自动签到，结果通过系统通知送达桌面：

  • ✅ 成功 — "WorkBuddy 签到成功：+50 积分"
  • ℹ️ 已签 — "Trae 今日已签到，没有重复领取"
  • ⚠️ 需人工 — "需要重新登录"

详细功能、故障排查、卸载清理请看 docs/GUIDE.md。

视频教程录制方法：按 Win+G 打开 Windows 游戏栏，选择本教程所在窗口录制即可。所有步骤都有明确的视觉指示，可以照着真人操作录制。

祝你签到愉快 🎉
