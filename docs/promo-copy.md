## 二、技术社区文案（V2EX / 掘金 / 知乎 / OSChina / 少数派）

### 标题

用 Tauri 2 + Rust 写了个 Windows 托盘签到工具，开源了

### 正文

每天要记得去好几家 AI 产品领免费额度（WorkBuddy / Trae / Qoder / 秒哒），很烦。于是写了个 **SignDock**：Tauri 2 + Rust 的 Windows 托盘常驻小工具，按你配置的时间自动把这几家的每日免费额度领了，结果走系统通知，历史存本地 SQLite。

几个有点意思的技术点：

- **凭证零输入**：Trae / Qoder 直接读本机登录态；WorkBuddy 5.6 起本机凭据被厂商加密，改走官方 OAuth 轮询登录（这里踩过坑：服务端返回 `code=11217 "login ing..."` 被当成失败，导致永远拿不到 token，v0.1.1 已修）；秒哒不读浏览器，用自有登录窗口封存 cookie。
- **凭据安全**：用 Windows DPAPI 封存，换用户 / 换机器解不开，需重新登录一次。
- **调度细节**：触发时间带确定性 jitter（只往后推），避免整点集中请求；临时网络失败按配置补偿重试，凭证过期不重试。
- **边界克制**：单账号、单机器、不碰多开 / 批量 / 账号切换，守住厂商风控边界。

绿色版约 4.6MB，免安装。仓库已开源（MIT），求 Star / Issue / PR：
`https://github.com/xiangsir4088/signdock`

声明：调用的是厂商非公开接口，随时可能变更或下线，功能不保证持续可用；仅限个人单账号自用。
